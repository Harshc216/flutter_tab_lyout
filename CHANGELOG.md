## 0.0.1

* Initial release of `flutter_tab_layout_library`.
* Added `ModernTabLayout` combining tab bars and swipeable page views.
* Added `ModernTabController` supporting next/prev navigation actions.
* Added support for multiple indicator styles (Material, Pill, Gradient, Glass, Floating, Underline) utilizing custom canvas painting.
* Added real-time scroll synchronization between TabBar and TabView gesture dragging.
* Added dynamic page transition styles (Slide, Fade, Scale, SlideFade).
